# Sai8555 Tap

## How do I install these formulae?

`brew install sai8555/tap/<formula>`

Or `brew tap sai8555/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sai8555/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
